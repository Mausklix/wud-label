# WUD Label Generator

Ein Tool zur Erstellung von Docker Compose Labels für [What's Up Docker (WUD)](https://getwud.app/).

## Features

- Generiert WUD-Labels für Docker Compose, Docker CLI, Swarm, Kubernetes und Nomad
- Automatische Regex-Vorschläge basierend auf dem Image-Tag
- Vordefinierte Beispiele für gängige Images
- Unterstützt alle WUD-Label-Optionen

## Nutzung

Öffne index.html im Browser – kein Server nötig.
